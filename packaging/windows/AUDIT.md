# Windows packaging audit

- Entry point: `python main.py`, CPython 3.11 x64. `main()` builds `ui.JarvisUI`, which creates QApplication and the original MainWindow. The Gemini Live worker starts in a background thread after first-run configuration.
- UI: `ui.py`, `personality_joystick.py`, `config/*.mp4` and `jarvis.ico`. No UI source changes are needed. The source refers to `face.png` and `config/home_scene.png`, but neither exists in this checkout; the existing video background is bundled.
- Runtime: `main.py`, `core/`, `Personality/`. Built-in actions and plugins are discovered from actual `.py` files using importlib; personality profiles are also discovered by file. All are kept as original files in the private application directory.
- Voice: main Gemini audio stream uses sounddevice/PortAudio and NumPy. Optional local STT/TTS dependencies are included; optional speech models retain their existing first-use downloads. Wake-word models and the Playwright browser are build-time resources.
- Memory/configuration: `memory/` and `config/` Python modules are bundled. Personal `memory/long_term.json`, developer API keys, OAuth tokens, `.env` and private certificates are excluded. Existing setup collects a user's Gemini key. Writable state persists under LocalAppData.
- Windows access: subprocess, ctypes, pywin32, pycaw, WMI, pywinauto, pyautogui, capture and clipboard modules. The package includes native wheels and their DLLs. External targets such as Blender, phones and service accounts remain necessary for the corresponding integrations.
- Mobile/dashboard: `dashboard/server.py` and static resources remain an internal feature of the desktop runtime. They are bundled unchanged and are not deployed as the product UI.
- Paths: source mixes `__file__`, working-directory paths, `sys.frozen` executable paths and subprocess `sys.executable`. A private CPython child keeps `sys.frozen` false and `sys.executable` usable as Python, avoiding changes to those app paths. The app's working directory is its private persistent application directory.
- Development fallback: barehands references `D:\CLONES\HandsMode`; its bundled local `barehands/` directory takes precedence. Bundled tool directories are placed before the host PATH.
- Environment: Gemini/tool settings include GEMINI_API_KEY, CHIDVI_BUILDER_MODEL and CHIDVI_BUILDER_PORT. Optional model code uses HF_HUB_OFFLINE, TRANSFORMERS_OFFLINE, HF_DATASETS_OFFLINE, USE_TF and TOKENIZERS_PARALLELISM. Standard Windows APPDATA/LOCALAPPDATA/ProgramFiles variables remain native. The launcher removes inherited PYTHONPATH, PYTHONHOME, VIRTUAL_ENV and Qt plugin overrides and supplies its private runtime/browser paths.
- Dependencies: `requirements.in` includes the repository requirements plus optional imports discovered in the audit. `requirements-lock.txt` records exact resolved versions. `tools-lock.json` records portable-tool download URLs and SHA256 values. Third-party distribution metadata and licenses remain bundled.
- Existing source limitation: `actions/app_builder.py` does not supply the handler expected by ActionRegistry; the original loader rejects it. The baseline is 18 valid actions and 7 plugins. Packaging does not change that source behavior.
